Distributed RL rollout engine

## Developer setup

This project uses **uv** for dependency management.

### Prerequisite

Install `uv` if you haven't already:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### Setup environment and pre-commit hooks

The project is automatically initialized with `git` and local dependencies/pre-commit
environments when generated by Copier. If you need to re-run these manually:

```bash
uv sync --group dev --group notebook
uv run pre-commit install \
  --hook-type pre-commit \
  --hook-type commit-msg \
  --hook-type pre-push
```

### Running tests

Run the test suite with coverage reporting:

```bash
uv run pytest
```

Check the coverage threshold rules:

```bash
uv run coverage-threshold
```
